# MineWeb — 我的世界 Web 版

一个用 **原生 JavaScript + WebGL2** 手写的体素沙盒引擎，在浏览器里复刻《我的世界》的核心玩法：
无限地形、挖掘建造、生存数值、生物、昼夜循环、合成、存档。**没有使用 Three.js / Babylon 等任何
3D 库，也没有任何美术资源文件** —— 所有方块贴图、音效、UI 图标都是代码程序化生成的。

```
双击  start.bat        （Windows：启动本地服务器并打开浏览器）
或者  powershell -File start.ps1
或者  node tools/serve.mjs 8137   然后访问 http://127.0.0.1:8137/
```

> 需要 **支持 WebGL2** 的浏览器（Chrome / Edge / Firefox 现代版本均可）。无需安装任何依赖。

## 1. 帧率（本项目的硬性指标）

在本机（Intel Core Ultra 5 125H + Intel Arc 核显，Chrome + ANGLE/D3D11）实测：

| 场景 | 分辨率 | 渲染距离 | 平均帧率 | 1% 低帧 | 99 分位帧耗时 | 最差帧 |
|---|---|---|---|---|---|---|
| **修复渲染后（当前）** | 1600×900 | 8 区块 | **119.2 fps** | **117.6 fps** | **8.5 ms** | 25 ms |
| 同上复测 ×3 | 1600×900 | 8 区块 | 118.7–119.4 fps | 117.6 fps | 8.5 ms | — |
| 修复前（网格损坏、且把 1.5 倍无效索引画出来） | 1600×900 | 8 区块 | 118 fps | 59.9–60.2 fps | 16.6 ms | 33 ms |

该帧的渲染规模：**98 个绘制批次 / 10.4 万四边形 / 289 个区块 / 69 MB 内存**。

游戏逻辑单帧成本为 **0.125 ms**（约 8000 fps 的逻辑上限），说明瓶颈完全在 GPU 光栅化，
且仍有大量余量 —— 把渲染距离拉到 12 区块仍然稳定在 60 fps 以上。

复现方式：

```bash
node tools/serve.mjs 8137                              # 终端 A
node tools/bench.mjs http://127.0.0.1:8137/ shots 10   # 终端 B：真实 Chrome + CDP 采样
```

`tools/bench.mjs` 会启动真实 Chrome，用 `Runtime.evaluate` 在页面内通过 `requestAnimationFrame`
统计 10 秒内的**真实帧间隔分布**，输出平均值、中位数、1% 低帧、99 分位与最差帧耗时，并截图存档
（报告见 `reports/bench-report.json`）。

保证 60 帧以上的工程手段：

- **每个区块一个 VAO/VBO**，顶点**完全展开**（每个四边形 6 个顶点、无索引复用），
  因此用 `drawArrays` 直接绘制。这是修掉一个长期渲染 bug 后的正确形态：
  之前网格发出的是 6 顶点/四边形，而索引缓冲按 4 顶点/四边形生成，
  结果是索引指向错误顶点、并且只覆盖 2/3 的几何 —— 画面表现就是地面满是黑色三角缺口、
  方块被拉成扇形；
- **方块贴图用 WebGL2 纹理数组**（`TEXTURE_2D_ARRAY`，一个 16×16 层 = 一种方块面）。
  这是体素渲染里关键的一步：把图集打包进单张 2D 贴图就无法开启 mipmap（粗 mip 会把
  相邻方块平均到一起，远处地面变成黑黄条纹），而纹理数组让每种方块拥有独立的 mip
  金字塔，于是**既能开 mipmap 消除远处闪烁，又不会串色**；
- **顶点级面剔除 + 环境光遮蔽烘焙**，不可见面根本不进入显存（一个典型区块约 3–5k 四边形）；
- **视锥剔除**（每区块 AABB vs 6 个视锥平面），视野外区块 0 绘制调用；
- **天空用 `gl_VertexID` 单三角形**绘制，不占顶点缓冲；太阳是真正的**世界空间**天体
  （逐像素重建视线方向 → 圆盘 + 光晕 + 地平线暖光），不再是贴着屏幕的假光斑；
- **时间片调度**：地形生成 / 装饰 / 光照 / 网格构建每帧**共享同一个 1.35×6ms 截止时间**，
  区块上传也很近优先并限 2.5ms —— 之前每个阶段各带自己的宽松倍数，
  单帧最坏能花掉 20ms 以上，这正是 1% 低帧卡在 60 边缘的原因；
- **自适应渲染距离**：连续 12 帧平均低于 55 fps 时自动下调 1 区块并提示，反之逐步恢复；
- 渲染距离（3–22 区块）、雾、FOV、最大帧率等都能在设置里实时调整。

## 2. 已实现的功能

### 世界
- **无限地形**：分形值噪声大陆 + 山脊噪声山脉 + 细节噪声，128 格高，海平面 62；
- **11 种生物群系**：海洋、沙滩、平原、森林、沙漠、热带草原、山地、雪原、针叶林、丛林、沼泽，
  各自的表层方块、植被密度、树种、雪/沙/冰表现都不同；
- **洞穴系统**：两层蠕虫噪声交叉 + 深层大空腔，深处有岩浆湖；
- **矿物分布**：煤 / 铁 / 金 / 钻石按深度概率生成，另有砂砾与黏土矿脉；
- **植被**：橡树、白桦、云杉（锥形）、丛林巨树、仙人掌、花、南瓜，树冠可跨区块生长；
- **水体**：海洋 / 湖泊按海平面填充，雪原结冰，水面比方块低 1/8 格并半透明混合。

### 光照
- **天光 + 方块光双通道**洪水填充，读取 3×3 区块邻域，洞穴口、门口、屋檐下的光都能正确外溢；
- **平滑光照**：逐顶点对 4 个采样点取平均，配合**环境光遮蔽（AO）**和面朝向明暗，
  方块棱角有真实的暗角过渡；
- **火把 / 荧石 / 岩浆**发光并即时传播（放下火把立刻照亮周围）；
- 昼夜循环 20 分钟一天，天空颜色、雾色、太阳位置、天光强度连续变化。

### 玩家与交互
- AABB 体素碰撞、重力、跳跃、行走/疾跑/潜行、水中游泳与呼吸条、台阶自动踏上；
- **创造模式**：双击空格或 F 键切换飞行，飞行速度加倍（Ctrl 疾跑）；
- **生存模式**：生命 20、饥饿 20、饱和度、摔落伤害、溺水、饥饿掉血、自然回血、经验与等级；
- **挖掘**：按方块硬度计算进度（`hardness` 表），显示破坏进度框与碎屑粒子，不同方块不同音效；
- **放置**：面法线定位、禁止放在玩家身上、植物需要下方实体方块、创造模式不消耗物品；
- **中键取色**、**Q 丢弃物品**、**掉落物自动吸附拾取**；
- 第一人称手持物品（含走路摆动与俯仰跟随）、准星、方块高亮描边。

### 物品与合成
- **方块 + 物品双体系**：方块 id 0–127，物品用负数 id（`core/items.js`，**55 种**），
  共用同一条 `ItemStack` 通道、同一套背包与存档格式；
- **完整工具链**：木/石/铁/钻石 × 镐/斧/锹/剑/锄 = **20 件工具**，
  各有挖掘速度倍率与耐久（木 60 → 钻石 1562）；
  只有用对口工具挖对应方块才吃到倍率，用错工具只有 1×（空手挖石头很慢）；
- **材料物品**：木棍、煤炭、木炭、铁锭、金锭、钻石、黏土球、砖、燧石；
- **食物**：苹果、面包、生猪排、熟猪排（按 R 进食，恢复饥饿）；
- **矿石掉落物**：煤矿→煤炭、铁矿→铁锭、金矿→金锭、钻石矿→钻石、砂砾→燧石，
  与 MC 一致（挖矿拿到的是材料，不是原矿方块）；
- **2×2 个人合成格**：木板、木棍、火把、工作台、熔炉、箱子、砖块……（基础配方）；
- **3×3 工作台**：右键工作台打开，共 **62 条配方**（含全部 20 件工具、4 种弓、20 件盔甲）；
  2×2 格子会正确拒绝只有工作台才能做的配方；
- **配方书**：按当前格子大小过滤，点一下就把材料自动摆进合成格；
- **熔炉**：右键打开，输入格 + 燃料格 + 输出格，8 条烧炼配方
  （沙子→玻璃、圆石→石头、铁矿→铁锭、金矿→金锭、黏土→砖、原木→木炭、生猪排→熟猪排）；
  燃料按秒计（煤炭 80s、木板 15s）；**燃烧中的熔炉会变成发光的「燃烧的熔炉」并照亮周围**；
- **箱子容器**：右键箱子打开 27 格箱内存储，与背包之间可自由搬运；
  箱内物品按坐标保存进存档，关掉游戏再进来东西还在；
- **盔甲（20 件）**：皮革/铁/金/钻石 × 头盔/胸甲/护腿/靴子，
  背包右上角有 4 个装备槽（只接受对应部位），每点护甲吸收约 4% 伤害（上限 80%），
  挨打时护甲同步掉耐久，损坏后消失；
- **弓与箭**：右键开始拉弓（1 秒拉满），松开发射；箭的初速与伤害随拉弓时间线性增长
  （18–60 格/秒，伤害 2–10），需要背包里有箭，命中生物造成伤害并击退，
  落地后可以捡回来；弓有 4 个材质等级与各自耐久；
- 工具/盔甲在格子里会显示**耐久条**（绿 → 黄 → 红）；
- 左键拿取 / 右键分半 / Shift 快速移动 / 光标跟随手上物品，与 MC 操作习惯一致；
- 创造模式调色板包含全部 55 种方块与 33 种物品。
- **朝向方块**：熔炉 / 箱子 / 南瓜 / 铁砧放置时自动朝向玩家，右键可旋转朝向；
  朝向存在区块的平行字节数组里，方块字节保持为干净的 id。

### 农业与睡眠
- **锄头开垦**：手持锄右键泥土/草方块 → 耕地（消耗锄的耐久），耕地有垄沟纹理；
- **种植**：草方块被破坏会掉落**小麦种子**，右键耕地下种；小麦有 **4 个生长阶段**
  （贴图与植株高度都随阶段变化）；
- **随机刻生长**：每 0.25 秒在附近区块随机抽取少量方块做 tick ——
  这就是作物生长的驱动力（耕地上小麦生长更快），沙/砂砾也靠它自然塌落；
- **收获**：成熟小麦（第 3 阶段）破坏后掉落**小麦**，3 个小麦合成**面包**；
- **床**：3 羊毛 + 3 木板合成。夜晚右键床即可睡觉 ——
  **设置重生点**、淡出并跳到清晨、回复 4 点生命；白天睡觉会被拒绝并提示。

### 红石
一个**简化但忠实**的红石系统（不是完整的 MC 红石，见文末差距说明）。

- **电源**：红石块（常亮 15）、红石火把（常亮 15）、**拉杆**（右键开关）、
  **石按钮**（按下后 1.2 秒自动弹回）、**压力板**（玩家或生物站上去就通电）；
- **红石线**：强度 **0–15**，每格衰减 1；功率存在**独立的地图**里 ——
  不塞进只有 3 bit 的朝向字节，那样会静默截断 8 以上的强度；
- **用电器**：**红石灯**（通电换成发光方块 id，真正照亮周围）、
  **活塞**（通电伸出、把前方方块推走一格，断电缩回）；
- 线路改变时只重算**它所在的连通分量**（BFS + 多源衰减），一个门电路只碰几十个格子；
- 红石矿石破坏掉落**红石粉**；配套 10 条配方（红石块、红石火把、拉杆、按钮、压力板、红石灯、活塞、中继器、漏斗、发射器）；
- **中继器**：右键循环 **4 档延时**（0.1 / 0.2 / 0.3 / 0.4 秒）。它**只驱动朝向的那一格** ——
  不会从输入侧回灌自己（否则会自锁在开启状态），这使它既能拉长脉冲也能当时钟；
- **漏斗**：每 0.4 秒从**上方**容器吸 1 个物品、往**朝向**的容器送 1 个，右键打开 9 格界面；
  **被红石通电时停止搬运**（可以当开关用）；
- **发射器**：9 格容器，可被红石驱动（容器与配方已完成，抛射逻辑见差距说明）。

### 酿造与药水
- **酿造台**（烈焰棒 + 3 圆石）右键打开：上格放材料、下格放 3 个玻璃瓶，
  酿造一条 **20 秒**，进度条实时显示；材料/瓶子放错格子会被拒绝；
- **完整的酿造链**（16 种药水）：

| 步骤 | 配方 |
|---|---|
| 基底 | 水瓶 + **下界疣** → 粗制的药水 |
| 效果 | 粗制 + 闪烁的西瓜 / 恶魂之泪 / 烈焰粉 / 糖 / 岩浆膏 / 金胡萝卜 / 河豚 / 蜘蛛眼 |
| 腐化 | 治疗 / 迅捷 / 剧毒 + **发酵蜘蛛眼** → 虚弱 / 缓慢 |
| 强化 | 治疗 / 再生 / 力量 / 迅捷 / 剧毒 + **荧石粉** → II 级 |

- **10 种效果**：治疗（瞬间回血）、生命恢复、力量（近战 +3）、迅捷（速度 +20%）、
  抗火、夜视、水下呼吸、剧毒、虚弱（近战 −3）、缓慢（速度 −15%）；
- **右键喝药水**：留下空玻璃瓶，效果立刻生效；
- **效果条**：屏幕右上角显示全部作用中的效果与倒计时（有害效果标红）；
- 效果真的改变玩法：迅捷跑得更快、力量让近战更疼、抗火让你在岩浆里不掉血、
  水下呼吸不会溺水、**剧毒持续掉血但永远不会致死**（与原版一致）。

### 末地与末影龙
- **末地维度**：以原点为中心漂浮的**末地石主岛**（半径约 62 格，边缘由噪声打散），
  外圈散布小浮岛；天空是**近乎全黑的星空**，没有昼夜循环；
- **黑曜石柱阵**：10 根柱子环绕（半径 42），柱顶有**治疗水晶**；
- **末影龙 Boss**：200 生命，13 个部件拼出长身、双翼（会扇动）、头部与渐细尾巴；
  **飞行 AI**——平时绕岛盘旋保持高度，玩家靠近 34 格内改为**俯冲追击**，接触造成 6 点伤害；
- **治疗水晶机制**：只要还有水晶存活，末影龙每秒回复 2.5 点生命 →
  必须先拆柱子才能打死它，与原版一致；
- **Boss 血条**：屏幕顶部显示末影龙血量（紫色渐变条）；
- **胜利条件**：击败末影龙 → 掉落 500 经验、**弹出通关界面**、
  中心生成返回主世界的**末地传送门**（踩上去即回主世界）；
- 到达末地时落在**黑曜石平台**上，不会被卡在岩层里。

### 村民与交易
- **村民**白天在主世界游荡，**不会自然消失**；出生点附近会生成 2–3 个，方便第一时间找到；
- **右键村民**（空手）打开交易界面：上半部是村民的报价，下半部是背包与快捷栏，
  点一条报价即完成一次交换；
- **4 种职业**，各有独立价目表：

| 职业 | 收购（玩家给） | 出售（玩家得） |
|---|---|---|
| 农民 | 小麦 / 苹果 / 种子 | 面包 |
| 铁匠 | 煤炭 / 铁锭 | 铁镐 / 铁胸甲 |
| 图书管理员 | 纸 / 书 | 书 / **钻石** |
| 屠夫 | 生猪排 | 熟猪排 / 铁剑 |

- 报价是**村民种子的确定性函数**（同一村民永远给同一组报价），价格带小幅抖动；
  每个条目有**使用次数上限**，卖完显示「已售罄」；
- 交易成功给 **2 点经验**；物品栏放不下时会**掉在地上**而不是凭空消失；
- **绿宝石**是交易货币，也可以用 8 铁锭 + 1 钻石合成（不想交易时的保底途径）。

### 附魔
- **附魔台**（黑曜石 + 钻石 + 书）右键打开，左侧格子放**工具 / 剑 / 盔甲 / 弓**，
  右侧给出 **3 个附魔选项**（第 3 项需要 10 级，与 MC 一致），消耗**经验等级**；
- 选项强度随玩家等级提升，且**对同一物品是确定性的**（`物品 + 等级 + 槽位` 哈希），
  关掉再开不会白嫖重骰；每次重新打开附魔台才换一组，且每个选项只能用一次；
- **5 种附魔，各 3 级**：

| 附魔 | 适用 | 效果 |
|---|---|---|
| 效率 | 镐/斧/锹/锄 | 挖掘速度 +40% / 级（仅对**对口方块**生效） |
| 锋利 | 剑 | 近战伤害 +1 / 级 |
| 保护 | 盔甲 | 额外减伤 +4% / 级（与护甲值叠加） |
| 力量 | 弓 | 箭伤害 +2 / 级 |
| 耐久 | 全部装备 | 有 `L/(L+1)` 概率**不消耗耐久** |

- 附魔存在 `ItemStack.ench`（`{ key: level }`），**随存档一起保存**；
- 配套物品：**纸**（草 → 纸）、**书**（4 纸）、**书架**（3 木板 + 3 书）。

### 近战
- **左键挥击**可以攻击生物 —— 用**射线 × 生物包围盒**（与物理同一个盒）判定，
  因此**低头打脚也能命中**，和 MC 手感一致；
- 伤害来自手持物品：**剑 2–5**（木/石/铁/钻石），空手 **1**，再加**锋利**附魔；
- 命中带**击退**（沿视线方向推开 + 小幅浮起），剑消耗耐久，攻击冷却 0.32 秒；
- 挥击命中生物时**不会同时挖掉背后的方块**。

### 下界维度
- **下界传送门**：用黑曜石搭出 4×5 门框（内空 2×3），手持**打火石**右键点燃，
  紫色传送门方块亮起（自带 11 级光，半透明双面渲染）；
  **打火石** = 铁锭 + 燧石，64 点耐久；
- **走进去即传送**：站进传送门后切换维度，坐标按 **1:8** 缩放（与 MC 一致）；
- **下界生成**：不是高度图，而是「整块下界岩 + 双噪声雕刻出的洞穴网络」；
  底部 y≤31 是**岩浆海**，y≤4 与 y≥118 是**基岩**封底封顶，
  另有**萤石簇**（挂在上层）、**石英矿脉**、**灵魂沙**（低处地板）；
- **独立大气**：下界有自己的暗红雾与天空色；不跑天光洪水填充，
  而是铺一层微弱环境光，让**岩浆与萤石成为真正的光源**；
- **到达即建回程门**：传送过去时会在落点旁自动建一座回程门并清出落脚空间，
  保证「进得去、出得来」；回来时精确落回你出发的那座门；
- 两个维度的区块、箱子、方块改动**各自独立**保存。

### 结构与探索
世界生成时会按区块坐标确定性地放置 5 类建筑，**不依赖加载顺序**：
一个跨四个区块的房子会被它覆盖的每个区块各自发现并只建自己那部分。

| 结构 | 出现概率 | 内容 |
|---|---|---|
| 废弃小屋 | 10% | 圆石/木板残墙（随机缺口）、残缺屋顶、战利品箱 |
| 村庄房屋 | 10% | 完整木板墙、玻璃窗、门洞、圆石屋顶、箱 + 工作台 + 火把 |
| 水井 | 10% | 圆石围栏、井水、两根角柱带火把 |
| 地牢 | 8% | 地表下 12–22 格的圆石房间、荧石照明、**双战利品箱**、一条逃生走廊 |
| 废弃矿井 | 6% | 木质井架、竖井（最深 14 格）、梯子、底部补给箱 |

- **战利品按主题分级**：遗迹（木板/面包）、民居（木板/面包/火把/玻璃/木镐）、
  地牢（铁锭/金锭/**钻石**/箭/铁胸甲）、矿井（铁锭/煤/火把/箭）；
- 宝箱内容**在第一次打开时才生成**，是对「坐标 + 世界种子」的纯函数 ——
  同一位置的箱子每次、每次重开游戏都是同一份掉落，且不需要任何全局结构列表。

### 生物与战斗- **被动生物**：猪、牛、羊、鸡 —— 随机游走、受击逃跑、掉落经验；
- **敌对生物**：僵尸、骷髅、苦力怕、**蜘蛛** —— 夜间黑暗中生成、追击玩家、接触伤害；
  **骷髅会在 3–16 格外放箭**（箭与玩家用的是同一套实体与碰撞代码，带预判提前量）；
  **蜘蛛会跳扑**，并且撞墙时会顺着墙面往上爬；
  僵尸/骷髅白天会燃烧；苦力怕靠近后引爆（真实破坏地形 + 距离衰减伤害 + 击退）；
- 生物为多部件盒模型，腿部行走摆动、僵尸手臂前伸、受击红闪；
- 简单 AI：直线追击、跳跃越障、水中上浮、远离 96 格自动消失。

### 界面与系统
- 标题界面（可输入种子）、加载进度界面、暂停菜单、设置菜单、死亡/重生界面、聊天栏；
- 全中文 UI，所有文案与方块名都是中文；
- **调试信息（F3）**：帧率、坐标、生物群系、朝向、时间、光照、模式、区块数、绘制批次、
  四边形数、剔除数、实体数、渲染距离、内存占用；
- **命令系统（T 键聊天，`/help`）**：`/time set day|night`、`/tp`、`/give`、`/gamemode`、
  `/seed`、`/spawn`、`/kill`、`/weather`、`/fps`；
- **存档**：localStorage 保存种子、玩家位置/朝向/模式/生命/饥饿、36 格背包和所有方块改动，
  标题界面出现「继续上次的世界」；
- 设置项：渲染距离、FOV、鼠标灵敏度（1–20 档，对应 0.001–0.02 弧度/像素）、音量、亮度、
  最大帧率、雾强度、视角摇晃、垂直同步、调试信息、反转 Y 轴、平滑光照（自适应质量）。
- **鼠标视角**：指针锁定后用 `movementX/Y` 的**增量**驱动 yaw/pitch，
  灵敏度固定夹在 0.0004–0.02 弧度/像素之间，单次事件增量也夹在 ±250 像素 ——
  这样即使存档里残留了坏值或浏览器在锁定瞬间甩出一个巨大增量，视角也不会失控自旋。

### 音频
- 全部用 WebAudio 合成：不同材质的脚步声（草/沙/雪/木/石/砾）、挖掘声、破坏声、放置声、
  受伤、进食、入水、爆炸、升级音阶、各生物叫声。**没有任何音频文件**。

## 6. 与《我的世界》的差距（诚实说明）

目标要求「功能一模一样」，完整的 Minecraft 是十几年的工业级工程（红石、
村民交易、命令方块、大型结构、多人联机、模组 API……）。当前版本已经把
**核心沙盒循环**做完整并且可玩，但以下内容尚未实现：

- **要塞与末地传送门框架的自然生成**：末地可以直接通过 /dim end 或末地传送门进入，但生成要塞的完整结构还没做；
- **完整的红石**：有红石线/拉杆/按钮/压力板/红石灯/活塞/中继器/漏斗/发射器容器，
  但没有比较器、观察者、发射器的抛射物、矿车与铁轨、红石灯的强弱电区分；
- **命令方块**、刷怪笼、信标、附魔书与铁砧修复；
- **红石与活塞**（尚未实现）；
- **盾牌与三叉戟**：有弓和箭，但没有盾牌、三叉戟、药水箭；
- **要塞 / 下界要塞 / 末地城 / 林地府邸**：有废弃小屋、村庄房屋、水井、地牢、废弃矿井，但没有这些大型结构；
- **多人联机**（当前是纯单机）；
- **部分容器**：箱子可用，但漏斗、发射器、潜影盒还没有；
- **成就系统**、角色皮肤/模型、掉落物拾取动画。

这些都可以在现有架构上继续扩展 —— 例如新增工具物品只需扩展物品 id 空间，
新增维度只需把 `World` 换成按维度 id 索引的实例集合。
